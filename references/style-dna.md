
## 二、跨主题恒定特征

### 思维模式
- 五段式漏斗：**地域锚定 → 服务定位 → 风格细分 → 受众精准 → 情绪爆点**
- 永远从"地域 + 你是哪类脸/眼皮/受众"切入
- 不讨论"这个妆好不好看"，而讨论"这个妆适合哪类人/哪种场合"

### 结构框架
- 标题：地域｜风格｜情绪 Emoji
- 正文：（模仿账号必修复）真实化叙事 + 价格信号 + hashtag
- 评论区：一字"私"为主，偶尔具体回答种草

### 标志性表达
- ‼️ 收尾（原博主 56 次高频）
- ｜ 分隔器（159 次）
- 0️⃣6️⃣ 数字 emoji
- "{风格}{受众}的神"
- "真的不是{X}吗"
- "拉满了 / 夯到爆了 / 真的很爽！！！"

## 三、5 个主题子模板

### 主题 A：妆面展示（**默认主题，爆款占比最高**）

```yaml
适用场景: 单纯展示某个妆容，无客户故事 / 无招生信号
适应性思维: 用"风格 + 杂志感 / 原生感 / 换头"强调技术结果
结构: 标题 = 风格词 + 形容词 + Emoji；视频 9-25 秒；封面是顾客侧脸特写
语言: Emoji 偏 🌸💖🩵🎀；常用"真的不是杂志封面吗""淡颜的神"
代表爆款: 春季日系妆容🌸真的不是杂志封面吗 (2210赞)
标题公式推荐: A 服务卡 + C 反问 + E 体感动词
图片重点: 妆面整体 + 眼部细节 + 妆前妆后对比
```

```yaml

结构: 标题 = 数字身份 + 动作 + 月入金额 + ‼️；视频 60-120 秒
语言: 0️⃣6️⃣年 / 月入1w+ / 刚毕业 / vlog💐

```

### 主题 C：招生引流

```yaml
适用场景: 课程招生 / 周末班 / 1v5 小班课
适应性思维: 突出"性价比 + 短时间 + 小班 + 周末"降低入门门槛
结构: 标题 = 价格 + 班型 + 受众 + ‼️；图文 9 张；最后一张课程表

```

### 主题 D：客户改造

```yaml
适用场景: 真实客户的"前后对比 / 换头 / 爆改"
适应性思维: 用"单眼皮/方圆脸/肉脸"+"换头/爆改/换人种"戳同类受众
结构: 标题 = 受众 + 改造结果；图文/视频前后对比；封面用妆后照
语言: ✨💖；常用"换头 / 爆改 / 原地换头 / 淡妆换人种"

图片重点: 妆前裸脸 + 妆后特写 + 上身出片
```

### 主题 E：情绪短文

```yaml

适应性思维: 纯情绪 + 自带感叹号

```
