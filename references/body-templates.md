# 正文模板 ｜ 3 个字数版本（**合规版 v2**）

> 原博主 100% 笔记正文是 hashtag 堆砌——这是其最大缺陷。模仿账号必须**反向修复**：每篇都写真实化叙事。
>
> ⚠ **合规红线（来自 xiaohongshu-mcp 项目 README）**：
> - 小红书**官方重点打击"引流"内容**——正文里**不要出现**：工作室名+联系方式+"私我/私聊/约我/加微信/扫码"等导流话术。
> - 业务转化必须走以下合规通路：① 简介（BIO）写工作室+联系方式 ② 主页置顶笔记导流 ③ 评论区被问到才答 ④ 私信主动跟进
> - **正文 ≤ 1000 字 / 标题 ≤ 20 字（emoji 算 2 字符）**

## 正文公式（共 3 个组件 — **删了"价格/招生"那一条**）

```
1. 客户故事 / 灵感来源  (1-2 句)
2. 技术解读 / 化法关键  (1-2 句)
3. 情绪点 / 反差        (1 句，可选)
4. 话题 hashtag 3-5 个   ← 用 publish_content 的 tags 字段独立传，不进正文
```

**❌ 严禁出现在正文**：
- 工作室名（"X 化妆室"/"OUOU"/"桃九九"等）
- "约妆"作为业务邀请（标题里作 SEO 词无所谓，正文里出现就引流）
- "私我"/"私我宝"/"私聊"/"加微信"/"加我"
- 联系方式（手机/微信号/小红书号）
- "招学员"/"招生"
- "黔南州内同城可上门" 这种业务范围声明

## 版本 1 ｜ 精简版（80-100 字）

> 用于：视频笔记 / 快读用户场景

模板：
```
{客户故事 1 句}——{化法关键 1 句}。{情绪反差 1 句}。
```

样本（韩系单眼皮主题）：
```
客妹自己单眼皮淡颜，化妆店从来不化她——这次用『冷调银光卧蚕+奶茶唇』反向救她。出门第一句"我是不是去韩国了"她当场笑哭。
```

字数：72 字。**不要在正文末尾加任何引流话术**。hashtag 走 tags 字段。

## Hashtag 选择规则（走 publish_content 的 tags 字段独立传）

每篇 3-5 个 tags，**必须**按以下结构：

```
#{城市}化妆师  ← 第 1 个必带（本地 SEO 主词）
#{城市}约妆    ← 第 2 个必带（hashtag 中"约妆"是 SEO 词，平台允许；区别于正文里的导流"约妆"）
#{风格/受众}{化妆/妆容}  ← 第 3-4 个选 1-2（风格 SEO）
#{个人IP/化妆师vlog}     ← 第 5 个可选
```

候选高权重 tags：
- 地域：都匀化妆师 / 都匀约妆 / 黔南化妆师 / 贵阳约妆造 / 贵州约妆
- 风格：日杂妆容 / 韩系亚裔妆 / 单眼皮化妆 / 方圆脸化妆 / 千金妆 / 美式甜心妆
- 业务：化妆师vlog / 化妆师IP / 化妆师日常 / 小红书化妆师
- 场景：演唱会妆 / 生日妆 / 婚礼跟妆 / 旅拍化妆

> ⚠ **tags 字段也避免**：`#招生` / `#学化妆来找我` / `#私信预约` 等引流标签。

## 业务转化的 4 条合规路径

正文不能写引流——所以业务转化走以下：

1. **简介（BIO）** — 写工作室名 + 城市 + 业务关键词 + 接单时段（小红书允许简介里放业务信息）
2. **主页置顶笔记** — 第一条置顶可以是"工作室介绍"，含价目、地址、预约方式（这条本身可能也会被限流，但比正文里写安全）
3. **评论区互动** — 用户问"在哪""怎么约"时再答，**不主动邀约**
4. **私信跟进** — 用户主动私信，再答价目和预约
