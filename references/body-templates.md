# 正文模板 ｜ 3 个字数版本

> 原博主 100% 笔记正文是 hashtag 堆砌——这是其最大缺陷。模仿账号必须**反向修复**：每篇都写真实化叙事。本文件给 3 个字数版本（精简/标准/深度），按发布场景选用。

## 正文公式（共 5 个组件）

```
1. 客户故事 / 灵感来源  (1-2 句)
2. 技术解读 / 化法关键  (1-2 句)
3. 情绪点 / 反差        (1 句，可选)
4. 价格 / 约妆 / 招生信号  (1 句)
5. 话题 hashtag 3-5 个
```

## Hashtag 选择规则

每篇正文末尾 3-5 个 hashtag，**必须**按以下结构：

```
#{城市}化妆师  ← 第 1 个必带（本地 SEO 主词）
#{城市}约妆    ← 第 2 个必带（本地服务词）
#{风格/受众}{化妆/妆容}  ← 第 3-4 个选 1-2（风格 SEO）
#{个人IP}     ← 第 5 个可选（如 #化妆师Ariel搓搓 但都匀账号要用自己的 IP 名）
```

候选高权重 hashtag：
- 地域：都匀化妆师 / 都匀约妆 / 黔南化妆师 / 贵阳约妆造 / 贵州约妆
- 风格：日杂妆容 / 韩系亚裔妆 / 单眼皮化妆 / 方圆脸化妆 / 千金妆 / 美式甜心妆
- 业务：化妆师vlog / 化妆培训 / 周末化妆课 / 小红书化妆师
- 场景：演唱会约妆 / 生日约妆 / 婚礼跟妆 / 旅拍化妆

## 正文反爆款检查清单（**比标题更严格**）

发布前自检：

- [ ] 字数在指定区间（80/120/150 字 ±10）
- [ ] 至少 1 个具体客户细节（不是空泛形容）
- [ ] 至少 1 个具体产品名（NARS / Visee / 艾吉拉 / Three / 蜜丝佛陀 等）— 增加种草价值
- [ ] 含价格/约妆/招生信号至少 1 个
- [ ] hashtag 3-5 个，含 2 个地域 + 1-2 个风格
- [ ] 末尾不要超过 1 句广告语，避免被算法判定营销
