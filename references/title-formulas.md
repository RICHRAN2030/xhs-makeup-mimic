# 标题公式 ｜ 5 个爆款模板

> 5 个公式从原博主 292 条标题统计提炼。生成时按主题类型选 3 个公式，每个公式产出 1 条标题，共 3 个版本。

## 全局硬性约束

- 字数 **12-22** 字（小红书后台 20 字截断，预留 2 字缓冲）
- 至少 1 个 Emoji（从 ‼️✨💕🔥💖🫧🎀💐🌸🩵🐈⁉️📍🤎🤍 选）
- 1 个地域词：默认 `都匀`，可换 `黔南/贵阳/独山/三都/龙里/罗甸/贵定/平塘/惠水`
- 1 个风格词（韩系亚裔/日杂/樱花妹/单眼皮/方圆脸/淡颜/千金/甜心/小猫 等）

## 公式 A ｜ 服务卡式（**最稳，黄金公式**）

```
{城市}{业务}｜{风格修饰}{妆容名}{‼️|💖|✨}
```

适用：所有主题；小红书 SEO 截流核心公式（命中 52% 原博主笔记）

样本：
- 都匀约妆｜单眼皮神妆🐈韩系亚裔小猫感拉满‼️
- 都匀约妆｜方圆脸日杂神妆🌸真的爆‼️
- 都匀化妆师｜春日通透感日杂妆容🫧

## 公式 B ｜ 体感型（**口语化软广，不让人觉得在打广告**）

```
{风格}{妆容}{🩵|🌸}{口语体感词}
```

适用：A 妆面展示 / D 客户改造 / E 情绪短文

样本：
- 单眼皮韩系小猫妆🐈淡颜女生的天选 ins 风
- 樱花妹日杂🌸真的不是杂志拍出来的吗
- 方圆脸日杂妆🌸樱花妹原生透明感

## 公式 C ｜ 反问型（**互动率高，能引出 comments**）

```
{形容}{妆容}{Emoji}真的不是{X}吗
```

适用：A 妆面展示 / D 客户改造

样本：
- 这样化的单眼皮🩵真的不是韩国 vlogger 吗
- 方圆脸化日杂🌸真的不是樱花妹本人吗
- 这眼妆🐈真的不是宁艺卓 staff only 教程吗

## 公式 D ｜ 数字身份钩子（**vlog 类爆款公式，4245 赞同款**）

```
{城市}{业务}｜{数字身份}{动作}{钱/结果}{‼️}
```

适用：B 人设 vlog / C 招生引流

样本：
- 都匀约妆｜25 岁化妆师月入1.5w一日实录‼️
- 都匀约妆｜0️⃣6️⃣年女生学化妆月入8千‼️
- 都匀约妆｜单眼皮女生爆改成韩系小猫只用 30 分钟

## 公式 E ｜ 体感动词收束（**短而爽，情绪短文流派**）

```
{城市}{业务}{化成这样|做到这样}真的{很爽|很牛|夯到爆}！！！
```

适用：E 情绪短文 / A 妆面展示

样本：
- 都匀约妆化成这样真的很爽‼️🐈
- 都匀这家化妆工作室真的夯到爆了‼️
- 都匀约妆｜方圆脸化成这样真的换头‼️🌸

## 选哪 3 个公式（**按主题）

| 主题 | 推荐 3 个公式 | 理由 |
|---|---|---|
| A 妆面展示 | **A + C + E** | 主标 SEO + 反问引互动 + 体感收口 |
| B 人设 vlog | **D + A + C** | 钱钩子主标 + SEO 备用 + 反问验证 |
| C 招生引流 | **A + D + E** | SEO 主标 + 数字钩子 + 体感收口 |
| D 客户改造 | **A + B + C** | SEO 主标 + 体感修饰 + 反问引种草 |
| E 情绪短文 | **E + C + B** | 体感主导 + 反问点睛 + 软广 |

## 反爆款检查清单

发布前自检——以下 5 条命中任何一条，标题失败：

- [ ] 标题不到 12 字 → 信息密度不够
- [ ] 标题超过 22 字 → 显示截断
- [ ] 没有任何 Emoji → 视觉无亮点
- [ ] 没有地域词 → 失去本地 SEO
- [ ] 没有风格词 → 失去风格 SEO

## 与原博主的标题差异提示

原博主标题里**不会出现**的词，模仿账号也**不要用**：
- 北京 / 上海 / 杭州 / 广州 / 深圳（南京/都匀外的一线城市，地域错位）
- 高级感 / 极简（"高级"是低权重词，黔南不流行）
- 学院派 / 大师课（学院风词不符合"个人 IP 工作室"调性）
- 网红同款（原博主不蹭网红，模仿账号也别蹭）

原博主**高频但模仿账号慎用**的词：
- clean girl / 白女风 / 雀斑（一线长三角流行，黔南三四线冷门）
- 欧美 / 高级（同上）
