# 视觉多样性矩阵 ｜ 反格式化策略

> 本文档基于 19 张真实小红书化妆师爆款封面的视觉风格分析（2026-05 抓取）：博主"花里胡哨的小搓澡巾"12 张 + 跨地域高赞 4 张 + 贵阳本地化妆师 3 张。
>
> **目的**：避免 skill 输出"每天图都差不多"的格式化结果。每次生成时按本矩阵**随机抽签 + 智能组合**，让 10 个维度都有变化。

---

## 一、关键反格式化原则（**改造前 vs 改造后**）

| 维度 | 旧 skill 默认（错） | 真实爆款实际 |
|---|---|---|
| 角度 | 45° 侧脸为主 | **正脸 / 微侧脸占 80%**（半侧脸只是少数） |
| 背景 | 灰白渐变 / 咖啡馆 bokeh / 城市街头 | **70% 纯白影棚，没有场景化背景** |
| 灯光 | 影棚柔光箱顶光 + 黄金时刻 | **明显是手机原相机 + 简陋自然光也很多** |
| 构图 | 单图胸像特写 | **6 种构图模式（单大头 / 胸像 / 四宫格 / 妆前妆后双格 / 主图+小窗素颜 / 信息海报）** |
| 服装 | 3 张图同色系（白高领 / 米针织） | **服装色系自由，不需要统一** |
| 姿态 | "斜视镜头外右上方" | **8 种姿态库（双手托腮 / 点唇 / 抓帽子 / 比V / 摸脸 等）** |
| 腮红 | "杏粉色低饱和打侧颊" | **红橘 / 粉调高饱和也占很大比例** |
| 妆容色系 | 锁定单一风格 | **6 大色系自由组合** |

## 二、6 种构图模式（每次按主题随机选 1-2 种作 3 张图分工）

### 模式 A ｜ 单图大头特写
- 描述：极致大脸贴满画面，五官 + 妆容细节占 60-80%，发丝甚至溢出画面边界
- 适用：纯妆面展示 / 妆面细节
- 占比：30%
- 案例：博主"红酒感气血日杂"（cover_6 大脸特写）/ "今天花60块约的妆值吗"（other_1 极致大眼睛）
- prompt 关键词：`extreme close-up`、`face fills the entire frame`、`hair strands escape the frame edges`、`pores and skin texture visible`

### 模式 B ｜ 单图胸像
- 描述：头 + 肩部完整，画面含部分上衣领口
- 适用：妆面 + 妆面 + 服装搭配
- 占比：20%
- 案例：博主"厌世湿发烟熏"（cover_4 胸像 + 黑吊带）
- prompt 关键词：`chest-up portrait`、`includes shoulders and neckline`、`upper torso visible`

### 模式 C ｜ 四宫格多 pose
- 描述：4 张图拼合，同一妆面不同角度 / 表情 / 场景
- 适用：风格妆面 / 客户改造 / vlog
- 占比：25%
- 案例：博主"整颗银小猫妆"（cover_8 四宫格）/ "原生通透日杂"（cover_9 四宫格）
- prompt 关键词：`4-grid collage layout`、`same model 4 different poses`、`top-left/top-right/bottom-left/bottom-right`

### 模式 D ｜ 主图 + 小窗素颜对比
- 描述：主图大妆面 + 左下/右下角叠一个小圆框/小方框素颜对比
- 适用：客户改造 / 教程
- 占比：15%
- 案例：博主"小猫感韩系亚裔"（cover_2 左下小素颜）/ 贵阳"06年化妆师宅家约妆vlog"（other_6 左下圆框素颜）
- prompt 关键词：`main image with small inset overlay`、`small circular thumbnail at bottom-left showing bare-face version`、`picture-in-picture`

### 模式 E ｜ 妆前妆后大对比双格
- 描述：左右或上下平分两格，妆前 + 妆后等大对比
- 适用：客户改造 / 素人改造（**这种是高赞王道**）
- 占比：10%
- 案例：博主"当我发现客妹的优势"（cover_7 整图素颜 + 下方文字预告改造）/ "02年化妆师素人改造"（other_4 内嵌四格含妆前妆后）
- prompt 关键词：`split-frame before-after`、`top-half pre-makeup / bottom-half post-makeup`、`equal proportion`

### 模式 F ｜ 信息海报 / vlog 拼图
- 描述：纯文字课程表 / 价目表 / 钱钩子叠字 vlog 拼图
- 适用：招生引流 / 人设 vlog / 价格透明
- 占比：15%
- 案例：博主"小红书化妆师爆火课程表"（cover_3 纯信息海报）/ "00后化妆师在南京日入过万 vlog"（cover_11 vlog 钱钩子拼图）
- 用户明确**禁字**约束下：**这种模式只能后期 PS 加字，AI 出图阶段只能生成"妆面图素材"备用**

## 三、10 个视觉维度的可选值库（**每次生成从每个维度随机选 1 个**）

### 维度 1：人物角度（5 选 1）
- 正脸（50%）
- 微侧 15°（20%）
- 半侧 30°（15%）
- 3/4 侧 45°（10%）
- 大侧近正侧（5%）

### 维度 2：景别（4 选 1）
- 极致大头特写（脸占 80%+，发丝出框）
- 头部特写（脸占 50-70%）
- 胸像 + 头部（脸占 30-50%，含肩颈）
- 半身（脸占 15-30%，含部分上身）

### 维度 3：姿态（10 选 1）
- 静态无手势（最常见）
- 双手交叉托腮在下巴下方（爆款 cover_1 标志姿态）
- 单手贴脸 / 摸脸颊
- 食指轻点下唇
- 双手交叉于胸前
- 抓起头发整理 / 撩发
- 戴帽子 + 一只手扶帽檐
- 比 V 字 / 比心 / 眨眼
- 看向镜头外（侧视 / 上视 / 下视）
- 自拍式手机举高视角

### 维度 4：背景（5 选 1）
- 纯白影棚（最常见，70%）
- 浅米 / 浅灰柔焦（20%）
- 室内深色 / 自拍感（5%）
- 真实工作室杂乱（化妆台镜面 / 杂物）
- 单色饱和（红 / 蓝 / 绿）少见但有冲击

### 维度 5：灯光（5 选 1）
- 影棚柔光箱顶光 + 侧补光
- 手机原相机 + 屋内日光灯（粗糙真实）
- 自然窗光（侧光）
- 化妆台镜面灯（多颗白炽）
- 黄金时刻自然光（仅场景外景才用）

### 维度 6：肤质渲染（4 选 1）
- 通透感裸光底妆（毛孔可见）
- 油亮高光 dewy（千金 / 泰式）
- 哑光雾面 matte（韩系）
- 雀斑保留（"厌世湿发"风）

### 维度 7：妆容色系（6 选 1，与风格主线适配）
- 红橙饱和系（红酒感气血 / 暖红唇 + 红橘腮红）
- 哑光裸色系（奶茶豆沙 / 杏色腮红 / 韩系小猫）
- 冷调银光系（卧蚕银光 / 灰美瞳 / 韩系亚裔）
- 烟熏厌世系（深棕灰烟熏 / 半透红血丝眼）
- 粉调甜美系（樱花粉 / 杏粉 / 日杂方圆脸）
- 油亮饱和系（千金 / 泰式 / 多层 highlight）

### 维度 8：发型（7 选 1）
- 长直发大波浪（黑 / 棕）
- 长直发自然散发 + 空气刘海
- 蓬松大刘海半遮额头
- 低马尾 + 散落碎发
- 半马尾发夹 + 散乱
- 短发 bob 中分
- 高马尾或盘发 + 散落发丝

### 维度 9：服装（不强制 3 张图统一色系）
- 黑色基础款（吊带 / 高领 / T恤）
- 白色基础款（衬衣 / 高领针织 / 卫衣）
- 暖色系（红 / 棕 / 橙 高领或针织）
- 浅米 / 卡其（针织 / 麂皮）
- 鲜艳色（黄 / 绿 / 蓝 高领）
- 横条纹 / 印花
- 真实化妆围裙 + 客户衣领

### 维度 10：情绪 / 表情（8 选 1）
- 慵懒淡然（嘴唇微微张开）
- 自信微笑（嘴角小幅上扬）
- 严肃高冷（无表情正视）
- 调皮（眨一只眼 / 比 V）
- 厌世（垂眸 / 眼神放空）
- 性感野性（抿唇 + 微眯眼）
- 天真害羞（垂头 / 抿嘴）
- 元气阳光（大笑 + 牙齿）

## 四、3 张图分工 — 多样性自动组合规则

每次生成 3 张图时，按以下规则确保**3 张图之间也有差异**（不是同一模板套 3 次）：

```
图 1 主图（吸引点击）
  - 构图模式：A 大头特写 / B 胸像 / C 四宫格 / D 主图+小窗 / E 妆前妆后
  - 优先选当下主题高赞的模式（A/D/E 在客户改造类爆款最多）

图 2 细节 / 局部（种草）
  - 构图模式：A 大头特写（局部裁切）
  - 与图 1 维度对比：换角度（图 1 正脸 → 图 2 微侧）/ 换姿态（图 1 双手托腮 → 图 2 单手贴脸）

图 3 验证 / 上身（信任）
  - 构图模式：C 四宫格 / E 妆前妆后 / B 胸像（任选）
  - 与图 1/2 维度对比：换服装色系（图 1 黑 → 图 3 白）/ 换发型（图 1 大波浪 → 图 3 半马尾）
```

**核心反格式化原则**：

1. **每张图都不要重复图 1 的所有维度** —— 至少有 2-3 个维度变化（姿态 / 角度 / 服装 / 表情 / 背景饱和度）
2. **避免每天都用同一组合** —— 把以前用过的"组合签名"记到 `examples/used-combos.log`，下次生成时避开
3. **人物锁卡保持稳定，其他 9 维度全部多样化** —— 这是用户用素颜库做 cref 锚定时的关键

## 五、模仿账号专属 — 黔南本地审美适配观察

通过对比博主（南京）vs 贵阳本地化妆师（3 个样本），发现：

| 维度 | 南京博主（一线长三角） | 贵阳本地化妆师（**模仿账号应学这个**） |
|---|---|---|
| 妆容色系 | 5 个风格全做 | 暖红/暖橙 + 粉调甜美 占比更高 |
| 模特年龄 | 25 岁居多 | 18-22 岁居多（"06年"高频） |
| 构图 | 单图大头 / 妆前妆后 主导 | **主图 + 小窗素颜** + vlog 拼图 占主导 |
| 钱钩子 | "月入 1w+" | "60 块约妆"、"宅家约妆"、"上门约妆" |
| 服装 | 高级感（白高领 / 棕针织） | 接地气（普通卫衣 / T 恤） |
| 工作室感 | 影棚级别 | **真实化妆台镜面 + 杂物** |
| 标题 | "爆改 / 神妆 / 拉满" | "60 块"、"上门"、"价目表"、"避雷" |

**结论**：模仿账号应该**优先使用模式 D（主图+小窗素颜）和模式 F（信息海报）+ 暖红/粉调饱和妆容**，而不是博主的"日杂通透"高级感路线——黔南本地受众更买账"真实接地气"。

## 六、人物一致性 + 多样性的平衡

**冲突点**：人物锁卡（14 项）锁定脸的同时，必须允许其他 9 个维度自由变化。

**解决方案**：

```
人物锁卡（不变）  →  脸型 / 眼型 / 鼻型 / 唇型 / 肤色 / 发色 等 14 项

每张图独立抽签（变）  →  角度 / 景别 / 姿态 / 背景 / 灯光 / 妆容色系 / 服装 / 表情 / 构图模式
```

**用户自带素颜库的最佳用法**：

1. 用素颜库照片做人物 cref（GPT-image-2 / Nano Banana 2 上传作参考图）
2. 锁定 14 项人物特征
3. 让 skill 从多样性矩阵随机抽签其他 9 个维度，组合生成 3 张图
4. 即使每天都用同一张素颜库，因为其他维度随机组合，每天的图也不会重样

## 七、本次新 skill 的"反格式化抽签算法"

每次生成时，skill 应该：

```python
# 伪代码示意
def generate_three_images(persona_card, theme, used_combos_history):
    # 图 1：主图
    composition_1 = random.choice(['A', 'B', 'C', 'D', 'E'])
    angle_1 = random.choice(['正脸', '微侧15°', '半侧30°', '3/4侧45°'])
    pose_1 = random.choice(POSE_LIBRARY_10)
    bg_1 = weighted_choice(['纯白', '浅米', '深色', '工作室杂乱'], [0.7, 0.2, 0.05, 0.05])
    light_1 = random.choice(LIGHT_LIBRARY_5)
    color_palette_1 = pick_color_for_theme(theme)
    hair_1 = random.choice(HAIR_LIBRARY_7)
    outfit_1 = random.choice(OUTFIT_LIBRARY_7)
    emotion_1 = random.choice(EMOTION_LIBRARY_8)

    # 图 2：细节 — 至少 3 个维度与图 1 不同
    angle_2 = pick_different(angle_1, ANGLE_LIB)
    pose_2 = pick_different(pose_1, POSE_LIB)
    emotion_2 = pick_different(emotion_1, EMOTION_LIB)
    # 其他维度保持与图 1 一致（人物锁 / 灯光 / 背景 / 服装）

    # 图 3：验证 — 至少 4 个维度与图 1 不同
    composition_3 = pick_different(composition_1, COMP_LIB)
    angle_3 = pick_different([angle_1, angle_2], ANGLE_LIB)
    outfit_3 = pick_different(outfit_1, OUTFIT_LIB)
    bg_3 = pick_different(bg_1, BG_LIB)

    # 检查是否与历史组合重复
    signature = hash((composition_1, angle_1, pose_1, color_palette_1))
    if signature in used_combos_history:
        # 重新抽签
        ...

    return [img1_json, img2_json, img3_json]
```

**实操简化版**：每次输出时，从每个维度的可选值列表里手动选一个（避免连续 3 天选同一个）。把当天的组合签名记到 `examples/used-combos.log`。
