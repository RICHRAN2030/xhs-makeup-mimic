# 图片提示词模板 ｜ JSON 结构化 · 中文 · 多样性驱动 · GPT-image-2 / Nano Banana 2

> 本文档配合 `persona-anchor.md`（人物 14 项锁卡）+ `visual-diversity.md`（10 维度多样性矩阵）使用。
>
> **核心机制变更（v2）**：旧版每次输出 3 张图都用同一个模板填空（导致"每天图都差不多"）。新版每张图都从 `visual-diversity.md` 的 10 维度可选值里**随机抽签 + 智能组合**，保证 3 张图之间也有差异，每天的图也不会重样。
>
> **目标平台**：GPT-image-2 / Nano Banana 2（不输出 Midjourney 参数）

---

## 一、本文档的工作流（**重要变更**）

```
第 1 步：读 visual-diversity.md，理解 10 个维度的可选值
第 2 步：建立 Persona Lock Card（14 项人物特征不变 — 用户素颜库 cref 锚定）
第 3 步：为图 1 / 图 2 / 图 3 各自抽签，保证 3 张图至少 3-4 个维度有差异
第 4 步：按本文件 JSON 模板填入抽签结果
第 5 步：在 examples/used-combos.log 记录本次组合签名，避免下次重复
```

## 九、反格式化自检清单（**生成后过一遍**）

发布前对照以下清单，确保 3 张图不"千图一面"：

- [ ] 图 1 的角度、姿态、表情 **不要**和昨天的图 1 完全一样
- [ ] 图 2 与图 1 至少 3 个维度不同（角度 / 姿态 / 表情 必须各换）
- [ ] 图 3 与图 1 至少 4 个维度不同（含服装 / 发型 / 背景）
- [ ] 妆容色系不要连续 3 天用同一系列
- [ ] 构图模式不要连续 3 天用同一种（如果上周都是 A 大头特写，本周换 D 主图+小窗）
- [ ] 灯光不要总用"影棚柔光箱"，偶尔用"手机原相机日光灯"增加真实感
- [ ] 服装色系每周 3 种以上（黑 / 白 / 暖色 / 浅米 至少各出现 1 次）
- [ ] 表情不要总是"自信微笑"，偶尔加"厌世垂眸""调皮眨眼"

## 十一、常见问题（继承旧版）

### Q：每天的图还是看起来差不多怎么办？

A：按以下递进式干预：
1. **强制改构图模式**——上周都是 A 大头特写？本周开 3 天 C 四宫格 + 2 天 D 主图小窗
2. **强制改妆容色系**——3 天韩系冷调银光后，至少切 1 天红橙饱和气血
3. **强制改表情**——3 天慵懒淡然后，必须出 1 天调皮眨眼或元气大笑
4. **直接在 prompt 加"对照昨天的图，做出明显不同的视觉风格"**——多模态模型对这种元指令越来越敏感

### Q：用户的素颜库照片只有 1 张，能保证 3 张图都像同一个人吗？

A：能。1 张素颜库 + 14 项锁卡描述 + Nano Banana 2 / GPT-image-2 原生多图一致性，三重保障。但要注意：
- 素颜库照片质量要够（清晰、正脸、自然光）
- 每张图的 JSON 都要完整粘 14 项锁卡描述（不能省略）

### Q：能让 AI 复刻博主"双手交叉托腮"的标志姿态吗？

A：能。在姿态字段写：
```
"动作姿态": "双手在下巴下方交叉，手指交错，肩膀略前倾，模特直视镜头"
```
这是博主 cover_1（2210 赞爆款）的经典姿态，配双手交叉托腮的描述很稳。

### Q：四宫格 / 双格图是 AI 一次出还是后期拼？

A：**两种都可以**：
1. **AI 直接出**（推荐 Nano Banana 2）：把整张四宫格描述写进一个 JSON，让模型一次出
2. **后期拼**：单独生成 4 张胸像，自己用 Photoshop / Canva / 美图秀秀拼

Nano Banana 2 直接出四宫格效果尚可，但格内人物一致性可能波动；后期拼更稳但费时。

### Q：禁字约束和真实爆款"图上加字"冲突怎么办？

A：用户明确要求禁字，所以 skill 输出的图都不加字。如果你想要"加字版"用作发布，可以**后期 PS 加字**——这样既享受 AI 高质量出图，又能加自己想要的文案。
