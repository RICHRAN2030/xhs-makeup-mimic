## 用户添加新图的「一句话入库」工作流

> 不要等到 70 张才入库——每批新图（5-10 张）就走一次入库流程。批量越早越能在生成笔记时用上。

**用户操作**：
1. 把新图放进 `H:\【项目】\小红书0\素颜库\`
2. 对 Claude 说任意以下一句：
   - "新图入库"
   - "读一下素颜库的新照片"
   - "把新加的图加进 persona 库"

**Claude 自动执行**：
1. `ls H:\【项目】\小红书0\素颜库\` 列出所有图片
2. 对比 `library-index.md` 已有"参考图绝对路径"，找出**没入过库的新图**
3. 对每张新图 Read 读图分析
4. 判断是"已有 Persona 的 multi-angle"还是"全新模特"：
   - **multi-angle**：把图路径追加到对应 Persona 的"参考图绝对路径"列表
   - **新模特**：分配下一个 Persona ID（P-I, P-J, ...），新建一段完整 14 项 JSON 追加到本文件
5. 更新顶部"已入库 / 当前 Persona 数"
6. 更新"风格-人物匹配速查表"
7. 提示用户"已入库 X 张，当前共 Y 张 / Z 个 Persona"

## 命名规则（约定）

- **Persona ID**：从 P-A 开始字母序递增（P-A, P-B, ... P-Z, 然后 P-AA, P-AB, ...）
- **Persona 名**：Claude 选一个 2 字中文昵称（避免与已有重名）
- **参考图绝对路径**：直接用素颜库里的文件名（不重命名用户的图）
